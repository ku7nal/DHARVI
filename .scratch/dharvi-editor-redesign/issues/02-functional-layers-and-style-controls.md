# 02 — Functional layers and style controls

**What to build:** Make the Dharvi layer browser and contextual style panel interactive, using reconstruction-domain terminology and connecting supported controls to the existing viewer.

**Blocked by:** 01 — Dharvi editor shell and branding.

**Status:** ready-for-agent

- [ ] Users can select a reconstruction layer and see its selected state in the dark panel.
- [ ] General, Data, Style, Hover, and Click tabs have usable active states.
- [ ] Supported opacity, size, density, color, and visibility controls update the relevant viewer or layer state.
- [ ] Existing reconstruction layer toggles and semantic/building visibility behavior continue to work.
