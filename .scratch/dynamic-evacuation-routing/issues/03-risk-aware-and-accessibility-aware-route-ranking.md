# 03 — Risk-Aware and Accessibility-Aware Route Ranking

**What to build:** Offer fastest, safest, and accessibility-friendly evacuation modes, ranking multiple route alternatives using distance, slope, water, debris, building proximity, and prediction uncertainty.

**Blocked by:** 02 — Dynamic Flood and Debris Avoidance

**Status:** ready-for-agent

- [x] At least three route profiles are available: fastest, safest, and accessible.
- [x] Each route displays distance, estimated travel time, risk score, and avoided hazards.
- [x] Steep terrain and uncertain predictions affect route ranking.
- [x] The selected route is visibly distinct from alternatives.
- [x] Tests verify stable ranking for each profile and sensible behavior when routes trade distance for safety.
